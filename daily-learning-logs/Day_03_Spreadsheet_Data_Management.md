# Day 02 – Spreadsheet Data Management and Quality Inspection

## 1. Objective

The objective of Day 03 was to understand data inspection, its importance, and the steps involved in identifying data-quality issues before making any changes to a dataset.

During this exercise, I created a separate working copy of the original dataset and added a dedicated worksheet named Data_Quality_Log to record identified issues, relevant details, validation requirements, and their respective statuses.

I preserved the original dataset as a reference for comparing changes and validating the working copy during subsequent data-cleaning activities.

This exercise also helped me develop an analytical mindset by understanding the importance of business requirements, investigating data-quality issues, and making informed decisions that can support better business outcomes.

## 2. Dataset description

This is a sample sales dataset which was generated by AI assistant. This dataset contains 7 fields or attributes they are:
Transaction ID: Represents id for each transaction
Date: Represents on which date transaction was done.
Product: Represents name of the product purchased.
Category: Represents which category the product belongs to.
Unit Price: Represents the price of the product.
Quantity: Represents number of quantity sold.
Revenue: Represents the total revenue on the transaction which is price * quantity

dataset contains 12 records.

## 3. Tools Used

Libreoffice Calc is the tool used to perform the operations.

## 4. Methodology

Today I worked on data inspection. 

Step 1: Created a working copy in a new worksheet so that we can perform all the operations on that and keep the original copy for future uses like cross verification.

Step 2: Found the Issues in the data, created new worksheet named data_quality_logs with fields Transaction id, Issue type, Issue Description, Expected Value, Status, Action Required to store the issues before moving to next step which is data cleaning.

Step 3: Issue types that are recorded in the sheet are Missing Value for transaction T012, Duplicate for Transaction T006, Improper capitalization for product names and Multiple date formats. Some of them should be validated using source records where as some of them should get confirmations from client for detailed data please download this sheet: [Day_03_Retail_Sales_Practice](https://github.com/jay-rapolu/data-analytics-portfolio/blob/main/01-spreadsheet-fundamentals/Day_03_Retail_Sales_Practice.ods)

## 5. Results and Findings

Findings are there are 3 records which have major issues those are one record T012 with Missing Revenue and 2 T006 records with same transaction id and different product details, some minor issues which are generated by AI for practice purpose which are improper capitalization for same product and multiple date formats.

Results are I have created new worksheet with all necessary details like issue type status of the issue action to be taken to resolve the issue. T012 and T006 should be validated with source data, capitalization issue and date format issue needs confirmation from the client.
